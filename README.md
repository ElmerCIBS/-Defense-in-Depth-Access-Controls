## 📌 Project Overview

This project explores the principles of **Defense in Depth** and **Access Control** in Cybersecurity, focusing on how multiple security layers help protect enterprise infrastructure against unauthorized access and potential security threats.

The objective is to understand how organizations can implement different security mechanisms to strengthen their infrastructure, reduce attack surfaces, and protect sensitive information.

## 🎯 Objectives

- Understand the Defense in Depth security strategy.
- Identify different Access Control models and their applications.
- Understand the importance of authentication and authorization.
- Analyze security risks within an enterprise infrastructure.
- Propose security controls to prevent unauthorized access.
- Explore the relationship between Least Privilege and Zero Trust.

## 🔐 Key Topics Covered

### 1. Defense in Depth

A cybersecurity strategy that uses multiple layers of protection to secure systems, networks, and data.

### 2. Access Control Models

- **DAC (Discretionary Access Control):** Access decisions are made by the resource owner.
- **MAC (Mandatory Access Control):** Access is determined by security classifications.
- **RBAC (Role-Based Access Control):** Permissions are assigned according to user roles.
- **ABAC (Attribute-Based Access Control):** Access decisions depend on attributes and conditions.

### 3. Identity and Access Management

- Identification
- Authentication
- Authorization
- Multi-Factor Authentication (MFA)
- Principle of Least Privilege

### 4. Zero Trust Architecture

Understanding the principle of never trusting automatically and continuously verifying access to systems and resources.

## 🏢 Practical Case Study: Enterprise Infrastructure

A simulated enterprise infrastructure was analyzed to identify potential security risks and recommend appropriate security controls.

**Identified Security Risks:**

- Credential theft and compromised passwords.
- Lack of Multi-Factor Authentication.
- Excessive user permissions.
- Insufficient network segmentation.
- Unauthorized access to sensitive database information.

**Proposed Security Controls:**

| Security Control | Purpose |
|---|---|
| MFA | Strengthen identity verification |
| RBAC | Assign permissions based on user roles |
| Least Privilege | Restrict unnecessary access |
| Network Segmentation | Isolate systems and reduce lateral movement |
| Secure VPN | Protect remote access |

## 🏗️ Defense in Depth Strategy

The proposed security architecture includes six protection layers:

1. **Physical Security:** Protecting equipment and servers.
2. **Perimeter Security:** Filtering external network traffic through firewalls.
3. **Network Security:** Separating networks using VLANs.
4. **Identity Security:** Implementing MFA and access permissions.
5. **Application Security:** Restricting access according to user responsibilities.
6. **Data Security:** Encrypting and protecting sensitive information.
